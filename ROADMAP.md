# Roadmap

Updated: 2026-11-11

features:
- package: Repo and release package: tools out of git, CI, the first-run tool check, the Linux and Windows packages
- dashboard: Honest Connected state and the dashboard with the battery temperature colour
- platform: The platform layer: Windows and Linux tools behind one interface, the native Linux relay, USB access without root
- service: qtetherd, the Linux tether service, and its status interface for the window and other clients
- decky: The Decky plugin for SteamOS Game Mode
- reconnect: Reconnect, liveness and a clean Disconnect
- cli: The quest-tether command line and the MCP server
- crash: Automatic crash reporting
- device-checks: Device checks before 1.0: the multi-hour soak and the open Windows questions
- design-pass: Design pass of the window and the Decky panel against the shared design system
- charge-control: Charge control while tethered (After 1.0)
- tuning: Efficiency, observability and peer-survey ideas (After 1.0)
- project: Goals, rules and status trackers

The stages, what is done and what is open: [docs/code-map.md, "Dev stages to 1.0"](docs/code-map.md#dev-stages-to-10).
